Northwind ERP REST API (v1)

All requests require the header X-API-Key: <your key>. Base URL: {{ base }}. JSON in, JSON out.

MethodPathDescription
GET/api/vendorsList vendors (vendor_id, name, legal_name, email, tax_id).
GET/api/billsList bills. Optional query params: vendor_id, invoice_number, status, due_after, due_before (YYYY-MM-DD).
GET/api/bills/{bill_id}Get one bill.
POST/api/billsCreate a bill. JSON body fields: vendor_id (e.g. V-001), invoice_number, invoice_date (YYYY-MM-DD), due_date (YYYY-MM-DD), amount (e.g. "1234.56"), currency (USD/EUR/GBP/INR), description (optional). Returns 201 with the created bill, 409 for duplicates, 422 for validation errors.

The API applies the same validation rules as the web form.
