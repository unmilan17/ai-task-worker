MethodPathDescription
GET/api/vendorsList vendors (vendor_id, name, legal_name, email, tax_id).
POST/api/vendorsCreate a vendor. Body: name, legal_name, tax_id (GSTIN), email. Returns 201 with the vendor.
GET/api/billsList bills. Optional query params: vendor_id, invoice_number, status, due_after, due_before (YYYY-MM-DD).
GET/api/bills/{bill_id}Get one bill.
POST/api/billsCreate a bill. JSON body fields: vendor_id (e.g. V-001), invoice_number, invoice_date (YYYY-MM-DD), due_date (YYYY-MM-DD), amount (e.g. "1234.56"), currency (USD/EUR/GBP/INR), description (optional), flagged (optional, true = flag for review). Returns 201 with the created bill, 409 for duplicates, 422 for validation errors.
PATCH/api/bills/{bill_id}Update fields of a bill (same field names as POST). Returns the updated bill.
DELETE/api/bills/{bill_id}Delete a bill.
GET/api/purchase-ordersList recorded purchase orders.
POST/api/purchase-ordersRecord a purchase order. Body: po_number, vendor_id, delivery_date (YYYY-MM-DD), notes.

The API applies the same validation rules as the web forms.
